# Residential Electrical Installation & Lighting Design

**[Click here to view the Full AutoCAD Project & DIALux Report (PDF)](https://github.com/user-attachments/files/29169536/IcTesisat.pdf)**

## Project Overview
This repository contains the comprehensive strong current (kuvvetli akım) electrical installation design and photometric lighting simulation for a 1,160 m² residential building. 

The project was drafted entirely in AutoCAD in strict compliance with Turkish Interior Installation Regulations (İç Tesisat Yönetmeliği), focusing on load scheduling, precise phase distribution balancing, and statutory voltage drop thresholds. Lighting simulations were conducted in DIALux using real-world commercial fixtures to validate visual comfort and energy efficiency metrics.

## Design Specifications

| Parameter | Value |
| :--- | :--- |
| **Total Construction Area** | 1,160 m² |
| **Total Installed Power (Kurulu Güç)** | 28.96 kW |
| **Total Demand Power (Talep Gücü)** | 13.03 kW |
| **Foundation Grounding Resistance** | 2.19 Ω |
| **Average Task Area Illuminance** | 550 lx |
| **Unified Glare Rating (UGR)** | 12 |

## Key Engineering Methodologies
* **Voltage Drop Analysis:** Executed critical calculations for the longest cable runs (achieving %e.t = 0.934), strictly maintaining levels well below the 1.5% statutory maximum for lighting and socket circuits.
* **Grounding System Design:** Calculated and verified the foundation grounding (temel topraklama) layout utilizing 30x3.5 mm galvanized strips, achieving a highly optimal equivalent resistance of 2.19 Ω.
* **Photometric Validation:** Utilized real-world photometric data (EAE NETALED 22W MID POWER LED) in DIALux to simulate spatial lighting. Confirmed a highly uniform (0.7) and glare-free (UGR 12) environment.
